# 🔑 触发方式参考

## 自动触发

| 方式 | 详情 |
|------|------|
| OpenClaw cron `ai-news-roundup-daily` | 每日 07:00 (Asia/Taipei) |

## 手动触发（自然语言）

| 你这样说 | Agent 做什么 |
|----------|-------------|
| "今天的 AI 新闻早报" | 读取 daily_data.json，做全流程策展 |
| "小羽毛，今天 AI 有什么新闻" | 同上 |
| "跑一下早报" | 检查数据有无更新，判断是否需要重新策展 |
| "今天的早报编辑了吗" | 检查今天的策展是否已完成 |
| "检查 daily_data" | 读取并报告 daily_data.json 概览（新闻数、来源、标签分布） |
| "再跑一遍早报" | 重新从候选池选文（上次选文被编辑了） |
| "给今天早报加一条新闻" | 从候选池追加一条，重新策划展 |

## 手动触发（飞书消息格式）

Agent 收到任何包含"新闻"+"早报"的飞书私信时，应考虑是否需要执行策展任务。
